# RelancePro AI V6

Version consolidée du prototype SaaS.

## Inclus
- Dashboard premium
- CRM + pipeline
- Prospects persistants dans le navigateur
- Recherche de chantiers en mode démo
- Géolocalisation navigateur
- Analyse photo en mode pré-analyse
- Préparation de brouillon de devis
- Comparaison avant/après
- Assistant IA en mode démonstration
- Relances
- Tarifs
- Export JSON
- Persistance locale
- PWA installable + cache offline du shell
- Design responsive desktop/mobile

## Pour la vraie production
Les services suivants doivent être branchés avec des comptes/clefs :
- Supabase : authentification et base de données multi-utilisateurs
- Fournisseur IA : vision + génération
- Sources/API de demandes de travaux autorisées
- Service cartographique/routage
- Email/SMS
- Stripe

Aucune donnée réelle de chantier n'est inventée : les annonces de démonstration sont signalées comme fictives.
